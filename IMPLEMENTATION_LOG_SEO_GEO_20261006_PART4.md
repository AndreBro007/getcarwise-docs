## A6 — llms.txt: RESOLVED (Part 3 said "blocked")
- **What happened:** André's WordPress activity log showed All in One SEO (AIOSEO v5.0.2.1) installed and activated by "Andre Broekman" shortly before Claude looked (assumed to be André's attempt to remove the stale file; not confirmed). With AIOSEO and Rank Math both active: the stale root `llms.txt` was replaced by an AIOSEO-generated one (25,903 chars, 85 links, overwriting Rank Math's curated content), and live pages carried DUPLICATE SEO tags (two meta descriptions, two canonicals, two og:titles, an extra JSON-LD block, checked on the $30k guide).
- **Fix:** AIOSEO → Sitemaps → LLMs.txt → "Enable llms.txt" turned OFF and saved (AIOSEO's documented way to remove its file); `/llms.txt` then served the Rank Math version. AIOSEO was then deactivated and deleted via the plugins API. Window with both plugins active was roughly 10–15 minutes (estimate).
- **Verified after deletion (live):** $30k guide has 1 title, 1 meta description, 1 canonical, 1 og:title, 3 JSON-LD blocks (back to normal); `robots.txt` has no AIOSEO text and lists `sitemap_index.xml`; `/sitemap_index.xml` 200; `/sitemap.xml` redirects to it; `/llms.txt` says "Generated by Rank Math SEO", no longer says "Under Review" and contains the curated "Key buying guides / Tools / CarClever app" section (about 16.8K chars). The one remaining "aioseo" string in page HTML is the previous admin URL recorded as a referrer in the MonsterInsights config, not a plugin remnant.
- **Search Console side effect:** AIOSEO had (re)submitted `https://getcarwise.app/sitemap.rss` (RSS; last read Apr 22, "submitted Oct 6"). Removed that one entry; remaining sitemaps (`sitemap.xml` index, `post-sitemap.xml`, `page-sitemap.xml`, `carclever-lite…/sitemap.xml`) all show Success.
- **Left behind:** AIOSEO database tables/options (not wiped; harmless clutter). A superseded claim: Claude earlier said only the host could remove the file because the WordPress root is "not writable"; AIOSEO could in fact write and replace it.
- **Lesson:** two SEO plugins active at once duplicate canonical/meta/schema output within minutes; never leave AIOSEO and Rank Math active together.
