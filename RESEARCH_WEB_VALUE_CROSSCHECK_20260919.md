## Publication standard established

For a page promising **new SUVs under $30,000**, use the **starting price including mandatory destination/freight** when that value is reliably available.

Do not classify a vehicle as a true new “under $30k” choice merely because its OEM headline MSRP excludes destination and falls below $30,000.

Recommended labeling:

- **Base MSRP** — manufacturer-advertised starting MSRP before destination.
- **Starting price incl. destination** — base MSRP + mandatory destination/freight, before tax/title/options/dealer fees.
- **Under-$30k status** — determined from starting price including destination, not base MSRP.

Where current sources disagree materially, publish the current OEM base MSRP plus a qualitative note rather than inventing an exact delivered/sticker figure.

# 2. Source discrepancies that matter

## Mazda CX-30 — use $27,970, not $27,870

Mazda raised CX-30 destination/handling to **$1,595 effective Aug 11, 2026**. The current base MSRP is $26,375.

Therefore the current normalized starting price is:

> **$26,375 + $1,595 = $27,970**

Some third-party pages still show $27,870, reflecting the earlier $1,495 destination charge. Use the OEM-current $27,970.

## Kia Niro — model year must be explicit

The current 2027 Niro Hybrid is **not** a true new SUV under $30k:

- base MSRP: $29,890;
- independent/current destination-inclusive start: $31,385.

The outgoing/remaining 2026 Niro Hybrid is still a valid sub-$30k example:

- base MSRP: $27,390;
- destination-inclusive start: $28,885.

Do not write “Kia Niro Hybrid starts under $30k” without specifying **2026**.

## Nissan Rogue — base MSRP is below $30k, purchase starting point is not

Current Nissan overview:
- base MSRP: $29,490.

Current Nissan destination disclosure:
- $1,545.

Normalized:
- **$31,035 before tax/options**.

Cars.com independently reports $31,035. Car and Driver currently shows $31,065, a small $30 discrepancy. Nissan + Cars.com are sufficient to exclude Rogue from the true new-under-$30k list.

## Hyundai Tucson — current sources are moving

Hyundai's current live model page now shows:
- **$29,700 base MSRP**, freight excluded.

Older/currently indexed Hyundai pages show $29,450, and independent destination-inclusive sources vary:
- KBB: $31,050;
- Car and Driver: $31,350;
- Cars.com: $31,350.

This appears to reflect price/freight timing differences.

Publication rule:

> **Do not use Tucson as a true under-$30k new choice. If mentioned, state that the current $29,700 headline MSRP excludes freight and the starting sticker exceeds $30k. Do not publish an exact all-in starting value until rechecked immediately before publication.**

## Hyundai Kona — independent sources agree on destination-inclusive sticker

- Base / XLT / Limited: **2.3-liter EcoBoost I-4**

## Kia used-owner powertrain warranty

Kia's official U.S. warranty manual states:

> the 120-month/100,000-mile Power Train Limited Warranty is an Original Owner benefit and **is not transferable to subsequent owners**.

Kia's official Certified Pre-Owned program is a separate case: qualifying Kia CPO vehicles receive a **10-year/100,000-mile CPO limited powertrain warranty** beginning from the original in-service date/zero miles.

Therefore public copy must distinguish:

- **ordinary used Kia:** do not imply the original owner's full 10/100 powertrain warranty transfers;
- **qualifying Kia CPO:** separate CPO coverage can provide 10/100 limited powertrain protection under the CPO program.

Sources:
- Kia warranty manual: https://www.kia.com/content/dam/kwcms/pr/es/images/owners/warranty-recalls/kia-warranty-manual-en.pdf
- Kia CPO: https://www.kia.com/us/en/cpo
- KBB CPO guide: https://www.kbb.com/cpo/kia-certified-pre-owned-program/

# 6. What cannot be cross-checked apples-to-apples

The exact Auto.dev/CarClever matching-pool counts, e.g.:

- RAV4 ~17,150 under the stated filters;
- Rogue ~30,129;
- PHEV model pools such as Prius Prime ~940 and RAV4 Prime ~488,

cannot be meaningfully "verified" by expecting Cars.com, Edmunds or another marketplace to return the same count.

Different marketplaces have different:

- dealer/feed coverage;
- refresh schedules;
- duplicate handling;
- geographic defaults;
- model naming;
- sold-listing latency;
- condition definitions.

External checks do confirm that these models have active, substantial U.S. used inventory, but not the exact Auto.dev denominator.

### Publication rule

If these counts are used, call them:

> **CarClever provider-reported matching inventory, checked [date]**

Round them and do not imply they equal all U.S. inventory.

Do not use them as a sole ranking criterion.

# 7. Final publication-safe value rules

1. **For "under $30k new," include mandatory destination.**
2. **Prefer current OEM pricing.**
3. When OEM pages and third parties disagree because of timing, use the current OEM base and avoid a falsely precise total.
4. Label model year explicitly, especially for Niro.
5. Do not derive median/average prices from CarClever's top-five shortlist.
6. Exclude implausible provider prices even if the tool did not flag them.
7. Treat Auto.dev pool counts as dated provider-reported availability signals, not audited national totals.
8. For used warranty claims, distinguish original-owner coverage from CPO and subsequent-owner coverage.
9. Use primary OEM specs for powertrain claims.
10. Recheck all price values immediately before WordPress publication because 2026/2027 pricing is actively changing.
