## 2. Defects found on our own site (high confidence, fixable)
**a. Broken schema on the priority page.** `/tools/best-compact-suv-under-30000/` has two hand-added JSON-LD blocks (ItemList + FAQPage) that WordPress `wpautop` filled with `<br />` tags, so they are **invalid JSON** (parsed locally, "Expecting value"). GSC URL Inspection: "Structured data with syntax errors — Incorrect value type" (crawled Sep 29). Result: the page's list/FAQ markup is unusable. No other page on the site has invalid JSON-LD.
**b. Orphaned money pages.** Using static HTML: the $30k page and the 3-row $50k page have **0 internal links** from anywhere (nav, hub, blog). Sitewide nav has 9 links (Home, About, Blog, Contact, Data Guides, Opt-out, Privacy, Terms, Tools) — no guide links. The `/tools/` hub links to only 8 of ~37 tool pages. ~13 vehicle pages ("2023 Honda CR-V…") and the truck/AI-native pages have 0 inbound. Caveat: JS-rendered menus would not show in static HTML.
**c. Thin pages.** hybrid-suv-under-20k 158 words, sedan-under-15k 153, used-electric-car 186. 13 vehicle pages ~400–1,000 words, no inbound links.
**d. Titles/meta.** Titles over 60 chars on ~25 pages (vehicle pages 65–89; `/we-tested…` 113; used-car-risk-analysis 94; financial-math 85); meta descriptions too short (53–78 chars) on 5 pages and over 160 (truncated) on ~10.
**e. E-E-A-T.** `author` = `claude-automation` on the $30k and 3-row pages (Andre Broekman on the PHEV page). Schema is Article+Person everywhere; no real reviewer/methodology byline on pillar pages.
**f. `llms.txt` is stale.** Generated by All in One SEO; says "App Status: Currently Under Review" while `/try-carclever/` says "Live on ChatGPT"; lists only 7 pages.
**g. Crawler access unconfirmed.** WordPress.com edge returns 403 "Checking search engine crawler… JavaScript required" to requests using GPTBot/ClaudeBot/PerplexityBot/Bingbot/Googlebot user-agents from my sandbox IP. This is probably spoofed-bot rejection, and real Googlebot demonstrably crawls fine (GSC: crawled successfully Sep 29). Whether real AI/Bing crawlers pass is **unknown**.
**h. Not problems:** one SEO plugin only emits front-end markup (Rank Math); titles/H1/canonicals are consistent on the 5 key pages; the "Small SUV" mismatch is fixed; the PHEV page is now ~3,000 words.

## 3. Ranked action plan

**Tier B — change the strategy (4–12 weeks)**
1. Stop treating "best SUV under $X" head terms as the growth bet (authority gap; 122 variants, 0 clicks). Keep those pages as supporting/GEO assets.
2. Own the intent we already win: "AI tools for comparing/buying used cars", "is this car overpriced", "deal score", "VIN check explained". Build a pillar "Best AI tools for buying a used car (2026)" with honest competitor comparisons (CarGurus Discover, TrueCar, Cars.com, Edmunds, Autotrader) built on the existing `we-tested…` data (already pos 9.3 for "does cargurus use ai…").
3. Q&A format on pillars: question as H2, 40–60-word direct answer first, then detail and cited sources — matches the question-style queries that already rank.
4. Original data as a link/citation engine: monthly "new vs used availability and price gap" from live inventory (mind the Auto.dev Starter ~1,000 calls/month cap), pitched to auto bloggers/Reddit/local press. Earned links are the only fix for Authority Score 2.
5. Entity/brand: consistent naming (CarClever as product, GetCarWise as publisher); Organization schema `sameAs` (ChatGPT app listing, LinkedIn, X, other real profiles); directory listings (Product Hunt, AlternativeTo) where genuinely applicable. The Reddit plan (ChatGPT lane) fits here.
6. Optimise the ChatGPT app directory listing copy (it ranks for the brand) and the pending Anthropic/Meta listings; make each link back to a specific site page.

**KPIs to replace head-term position watching:** non-brand clicks; brand-query impressions; AI-surface impressions (GSC generative AI report, 338 US in 28d); app-directory referrals; tool-usage events; referring domains (non-toxic).
